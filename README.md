Car Park IoT System
==================

A small scale prototype of the IoT ecosystem for a hypothetical car park
with modern features like,

- License Plate Recognition (LPR)
- Automatic price calculation
- Car park fill status indicator
- Visible display interface for drivers
- Payment processor integration (with RFID / QR)
- Interactable admin control panel (Web)
- External IoT platform integration (Home Assistant, Grafana)

<sub>Assignment project for an Internet of Things course.</sub>
